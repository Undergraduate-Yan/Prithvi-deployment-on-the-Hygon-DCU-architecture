# Third-party components and data

This repository contains experiment orchestration code and compact evidence produced around Prithvi-EO-2.0, TerraTorch, ONNX Runtime, MIGraphX, PyTorch, and the Sen1Floods11 workflow. Those projects, pretrained weights, datasets, container images, drivers, and runtime libraries retain their own licenses and terms.

No third-party pretrained weight, dataset, ONNX model, MXR cache, wheel, driver, or container image is redistributed here. Obtain each dependency from its official or otherwise authorized source and verify it with the identities documented under `artifacts/`.

The publication license for this repository's original source remains intentionally unset; see `LICENSE_PENDING.md` before making a public repository.
