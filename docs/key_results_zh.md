|---|---:|---:|---:|---|

M5 相对 FP32 的端到端 median 形式比值为 `1.005840×`，只低约 `0.5806%`，不能作为有实质意义的 INT8 加速结论。

## Kernel 与部署

- 33 个去重 hipprof trace、144 个候选/block 映射全部通过。
- 保留 INT8 的 block 均观察到 `I8II`；FP16 block 均观察到 `HBH`。
- 该结果证明 block 级 GEMM 路径，不证明整模型所有算子均为 INT8。
- M5 与 FP16 full 均完成 5/5 冷启动、3/3 恢复、K100-2/K100-3 smoke 和 3600 秒稳定性。
- 两个模型 60 分钟运行均为 0 错误、0 非有限输出、0 预测漂移。

## 永久保留的失败边界

- M0–M5 strict logits 等价未通过；任务级通过不能覆盖该结论。
- M0 原始 model-only CV 为 `6.474904%`，状态保持 unstable；追加确认不覆盖原始结果。
- M1–M4 相对同协议 FP32 更慢。
- M5 满足容量门槛，但不满足相对 FP16 full 的时延升级门槛。
