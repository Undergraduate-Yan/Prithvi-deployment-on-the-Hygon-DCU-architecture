# Repository utilities

- `repo_check.py`: checks layout, JSON/Python syntax, oversized artifacts, and common secret patterns.
- `verify_external_artifacts.py`: verifies downloaded model artifacts against size/SHA-256 identities.
- `summarize_results.py`: prints the compact paper and deployment tables.
- `generate_source_manifest.py`: regenerates `SOURCE_MANIFEST.sha256` after an intentional source update.

Run these from the repository root with Python 3.10 or newer.
